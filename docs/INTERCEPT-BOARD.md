# 拦截板需求（INTERCEPT-BOARD）

> 参考项目：**Lava FPGA**、**nestang**
> 尾板工作已暂停（见 `fc-tailboard/` [不在本仓库 / not in this repo]），本文件是拦截板的需求与范围定义。

---

## 1. 系统架构

```
FC 主板
 ├─ PPU（2C02，DIP-40）──► 拦截板 piggyback（公头插原座 + 母座收 PPU）
 │                         ├─ D0~D7   8 位数据总线（**双向**，需可强行置位）
 │                         ├─ A0~A2   3 条寄存器地址线
 │                         └─ /CS、R/W、时钟
 ├─ 复合视频 ──► 同步分离 ──► HSYNC / VSYNC
 └─ 音频（卡槽扩展音 45/46 + 主板混合主音）──► ADC 采样
                    │
                    ▼
        Tang Nano 20K（PMOD 排针插在拦截板上）
         ├─ 监控 $2000 / $4000 段寄存器状态
         ├─ 强制 PPU 进入 **RGB 输出状态**（寄存器置位）
         ├─ 结合 HSYNC/VSYNC + 音频
         └─ FPGA 内合成 HDMI ──► 初版 **480p**
```

**电源**：从尾板经 P1 取得 `+9V` / `+5V`；板上 **5V→3.3V LDO** 给电平转换器供电（3.3V 不在尾板上）。

## 2. 范围分期

### ✅ 第一期（最小化预研）
| 项 | 说明 |
|---|---|
| PPU piggyback 与总线接入 | 8 数据 + 3 地址 + 片选/RW/时钟 |
| **双向电平转换** | FC 5V ↔ Tang Nano 3.3V |
| 同步分离 | 从复合视频取 HSYNC / VSYNC |
| **音频采样** | ADC 前端 |
| 寄存器监控 + 强制 RGB 态 | $2000/$4000 段 |
| **480p HDMI 合成** | 核心目标：先证明"能出画面" |
| 电源 | 5V→3.3V LDO |

### ⏳ 后期再加入
| 项 | 备注 |
|---|---|
| **OSD 菜单** | BL616 侧做 UI |
| **调色板** | 指**用户可选/自定义**调色板；基础固定 RGB 映射属第一期 |
| **手柄拦截** | 含连发、未来"全模拟接管"；需在数据线上加切换器件 |
| **扫描线滤镜** | 视频后期效果 |

## 3. 硬件接口清单

| 类别 | 信号 | 方向 | 数量 |
|---|---|---|---|
| PPU 数据总线 | D0~D7 | **双向** ⚠️ | 8 |
| PPU 寄存器地址 | A0~A2 | 入 | 3 |
| PPU 控制 | /CS、R/W、时钟 | 入 | 3 |
| 视频同步 | HSYNC、VSYNC | 入 | 2 |
| 音频 | 模拟音（ADC） | 入 | 1~2 |
| 电源 | +5V、+9V（经 P1）、GND | — | — |
| PMOD | Tang Nano 两个 2×10 排针 | — | 2×20 |

> ⚠️ **数据总线必须双向**：Tang Nano 要"强行置位"寄存器，单向缓冲器做不到 → 决定电平转换器选型（如 74LVC245 / TXS 系列）。

## 4. 待确认（阻塞详细设计）

| # | 问题 | 影响 |
|---|---|---|
| 1 | **PPU 是 DIP-40 吗？** piggyback 形式（公头插原座 + 母座收 PPU）| 板框、两个 40 脚座 |
| 2 | **原 PPU 是否保留**（piggyback 时仍工作，只是被强制 RGB 态）| 数据总线冲突风险 |
| 3 | **同步分离**：用 LM1881 类现成芯片，还是 FPGA 内做？| 板上是否加 IC |
| 4 | **音频第一期做吗？**（需求列表里在第一期，但也可再后移）| ADC 与前端 |
| 5 | **拦截板尺寸/安装约束**？| 板框 |
| 6 | **首期是否只做视频、音频后移**？（最小化预研的取舍）| 工作量 |

## 5. 已知技术风险

| 风险 | 说明 |
|---|---|
| **数据总线双向 + 强制置位** | 与 PPU 同时驱动会冲突 → 需时序上"只在该写周期接管" |
| **5V/3.3V 电平** | FC 是 5V 逻辑；Tang Nano IO 为 3.3V，需确认是否 5V 容忍 |
| **PPU 时序苛刻** | PPU 总线在像素时钟下运行，拦截需按周期对齐 |
| **音频取点** | 卡槽 45/46 只有**扩展音**；主机 APU 主音需另取（见 `fc-tailboard/PROGRESS.md` [不在本仓库 / not in this repo] R43 的相关论证）|
| **HDMI 480p** | GW2AR-18 资源与时序是否能支撑 480p 合成，需预研验证 |
