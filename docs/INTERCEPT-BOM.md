## 2. 电平转换

**关键判断**：PPU 是 **5V TTL** 逻辑 ✓
- **5V → 3.3V（接收）**：用 **VCC=3.3V 的 74LVC 系列**，其输入**5V 容忍** ✓ → **可直接接收，无需额外电平转换** ✓✓
- **3.3V → 5V（输出）**：3.3V 输出对 5V TTL 的 VIH（≈2.0V）**绰绰有余** ✓ → **可直接驱动** ✓✓

**所以一颗 3.3V 供电的 74LVC245 就能双向转** ✓

| 项 | 规格 | 数量 | 候选 |
|---|---|---|---|
| **双向收发器** | 8 位，VCC=3.3V，5V 容忍 | **1** | `74LVC245`（DIP-20 封装优先）⚠️ 需核实是否有 DIP 版；无则用 SOP-20 + 转接板 |
| **单向缓冲器** | 8 位（地址 3 + 控制 3 + 预留）| 1 | `74LVC244`（同上）|

> 💡 **DIP 版 74LVC 现在难买** ✓ —— 备选：用 **74HC245**（5V 供电 ✗ 不能直连 3.3V FPGA ✗）不行 ✓
> **更实际的办法**：买 **SOP-20 转 DIP 转接板** + 贴片芯片 ✓（手焊 SOP-20 可行 ✓✓）

## 🔴 关键硬件要求（安全关键，已核实）

> 来源：emu-russia 逆向 wiki（pads.md / mux.md）、nes-ppu 文档、NESRGB 官方说明。
> **做错会烧 PPU** ⚠️

### ① EXT 引脚必须与主机侧隔离

| 事实 | 影响 |
|---|---|
| 2C02 的 **EXT0~3 = 14/15/16/17 脚** ✓ | 4 位**双向**色彩总线 |
| 方向由 **$2000 bit 6** 控制：**0=输入(slave) / 1=输出(master)** ✓ | ⚠️ **必须置 1** 才是输出 |
| **原装机器的 EXT0~3 是接地的** ✗ | 置 1 后 PPU 输出对地短路 → **烧 PPU** ✗✗ |

**⇒ 拦截板必须：PPU 的 EXT0~3 只接 FPGA，绝不接回主机侧** ✓✓
（这就是 NESRGB / HiDef NES 都做成"插在 PPU 座上"的原因）

### ② 第 5 位（BG/精灵）要从 VOUT 提取

| 事实 | 影响 |
|---|---|
| EXT 只有 **4 位** = 5 位调色板地址的低 4 位 | **缺一位** |
| 第 5 位（背景/精灵）**不在 EXT 上** | 必须从 **VOUT（21 脚）** 取 |
| NESRGB 做法：**比较器**从 VOUT 取 EXT4 + 消隐 + 同步 | 官方做法 |

**⇒ BOM 要增加**：**比较器 ×2~3**（LM339/LM393）+ 阈值分压电阻 + 从 VOUT 隔直引出 ✓
