## 0. 电源轨（网络名 → 实际电压）

| 网络 | 电压 | 来源 | 说明 |
|---|---|---|---|
| `RAW_IN` | 9V（5–12V） | 圆口经 J5.1 | **未保护**，反接会在此处出现负压 |
| `9V_IN` | 9V（5–12V） | `RAW_IN` 经 Q1（P-MOS 反接保护）| 送去电源开关 |
| `SW_B` | 9V（5–12V） | 开关返回，经 F1 保险丝 | 保险丝之后即 `+9V` |
| `+9V` | 9V（5–12V） | F1 输出 | U1 输入、P1.1、D1、C1 |
| `+5V` | 5V（5V 输入时约 4.7V） | U1（MP2315）输出 | 主板、P1.3、U4、J5.5 |
| `TN_VBUS` | 5V | **U4（理想二极管）或 J3 的 VBUS** | 供 Tang Nano 与 J4.1 |
| `GND` | 0 | — | 底层整块地平面 |

**无 3.3V 轨** —— 3.3V 由拦截板自行降压（LDO），尾板不提供。

## 1. P1 —— 板对板（尾板 ↔ 拦截板）
**型号**：`2X8PIN2.54`（LCSC `C9900027095`），2×8 = 16 脚

| 脚 | 网络 | 方向 | 说明 |
|---|---|---|---|
| 1 | `+9V` | 尾板 → 拦截板 | 可选使用（拦截板若不用可悬空）|
| 2 | `GND` | — | |
| 3 | `+5V` | 尾板 → 拦截板 | **拦截板 3.3V LDO 的输入** |
| 4 | `GND` | — | |
| 5 | `GND` | — | |
| 6 | `ENC_A` | 尾板 → 拦截板 | 编码器 A 相 |
| 7 | `GND` | — | |
| 8 | `GND` | — | |
| 9 | `GND` | — | |
| 10 | `GND` | — | |
| 11 | `ENC_SW` | 尾板 → 拦截板 | 编码器按下 |
| 12 | `ENC_B` | 尾板 → 拦截板 | 编码器 B 相 |
| 13 | `GND` | — | |
| 14 | `GND` | — | |
| 15 | `GND` | — | |
| 16 | `GND` | — | |

**接地比例：11 / 16 = 68.75%** —— 落实「排线防干扰」要求。
**编码器消抖在 BL616 侧做**（尾板不加施密特触发器）→ 拦截板/软件侧需启用内部上拉。

## 2. J5 —— 电源 / 开关 / 主板 焊接落点
**型号**：`2.54-1*8-BLACK`（LCSC `C9900192758`），1×8 直插（直接焊线）

| 脚 | 网络（**目标态**）| 说明 |
|---|---|---|
| 1 | `RAW_IN` | 圆口正极（内正）|
| 2 | `9V_IN` | → 电源开关（与脚 1 经 Q1 相通）|
| 3 | `SW_B` | 开关返回 → F1 输入端 |
| 4 | `GND` | 圆口外筒（外负）|
| 5 | `+5V` | **输出到 FC 主板** |
| 6 | `GND` | |
| 7 | `GND` | |
| 8 | `GND` | |

**线束**：圆口正极 1 根、外筒 1 根、开关 2 根、主板 5V 1 根、主板 GND 1 根。

> ⚠️ **当前实际状态与目标态不一致**：脚 1 仍为 `9V_IN`、脚 2 仍为 `SW_A`，且 Q1 尚未放置。
> 修复任务见 `PROGRESS.md` R45 与 `HANDOVER.md`「明晚从这里接着做」。

## 3. J3 —— 面板侧升级口（Type-C 母座）
**型号**：`TYPE-C-16PIN-L6.0`（LCSC `C9900201390`）

| 脚 | 网络 | 说明 |
|---|---|---|
| A4 / A9 / B4 / B9 | `TN_VBUS` | VBUS（4 脚并联）|
| A1 / A12 / B1 / B12 + **SHELL** | `GND` | 地 + 屏蔽壳 |
| A6 / B6 | `TN_DP` | USB D+ |
| A7 / B7 | `TN_DM` | USB D- |
| A5 | `TN_CC1` | CC1 |
| B5 | `TN_CC2` | CC2 |
| A8 / B8 | — | SBU1/SBU2，**NC** |

**用途**：PC 接入时读写 Tang Nano 的 TF 卡。**平时由 3D 打印盖板遮蔽**。

---

## 4. J4 —— Tang Nano 短线落点
**型号**：`2.54-1*8-BLACK`（LCSC `C9900192758`），1×8 直插

| 脚 | 网络 | 说明 |
|---|---|---|
| 1 | `TN_VBUS` | 给 Tang Nano 供电（PC 在时也由此进入）|
| 2 | `GND` | 信号地 |
| 3 | `TN_DP` | D+ |
| 4 | `TN_DM` | D- |
| 5 | `TN_CC1` | CC1 |
| 6 | `TN_CC2` | CC2 |
| 7 | `GND` | 信号回流 |
| 8 | `GND` | **仅接屏蔽层**（单端接地，避免地环）|

**线材**：带屏蔽的 USB-C 公头转散线，公头插 Tang Nano，散线焊 J4。
**⚠️ 必须带 VBUS** —— 否则不插电脑时 Tang Nano 没电。

---

## 5. SW1 —— 编码器
**型号**：`EC11`（LCSC `C2830186`），旋转 + 按下

| 信号 | 网络 | 去向 |
|---|---|---|
| A 相 | `ENC_A` | P1.6 → BL616 |
| B 相 | `ENC_B` | P1.12 → BL616 |
| 按下 | `ENC_SW` | P1.11 → BL616 |
| 公共端 C / D | `GND` | |

**机械**：装于原「拨动开关孔位」。
**消抖**：在 BL616 侧软件完成（不用 FPGA、不加硬件施密特）。

## 6. 信号电平约定

| 类别 | 电平 |
|---|---|
| `TN_*`（USB 相关）| **3.3V 逻辑**（Tang Nano 的 IO）|
| `ENC_A/B/SW` | **3.3V 逻辑**（BL616 内部上拉）|
| 电源轨 | 见 §0 |
